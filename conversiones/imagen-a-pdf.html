Cada imagen ocupa una página y se ajusta sin deformarse. Puedes cambiar el orden antes de crear el PDF.

    Preguntas frecuentes

    ¿Se envían mis imágenes a un servidor?

    No. Las imágenes se procesan en tu navegador y no se suben ni se guardan en un servidor.

    ¿Puedo incluir varias imágenes en un solo PDF?

    Sí. Cada imagen ocupa una página y puedes reordenarlas con los botones antes de descargar el documento.

    ¿El PDF sirve para cualquier trámite oficial?

    Genera páginas A4 verticales u horizontales, pero cada organismo puede pedir límites de tamaño, orientación o resolución distintos. Comprueba sus requisitos antes de enviarlo.

    ¿Se mantiene la calidad y el formato original?

    Las páginas se rasterizan a unos 200 ppp y se guardan como JPG, por lo que la calidad y el tamaño pueden variar. La imagen no se estira; el texto fotografiado no queda seleccionable.

    ¿Cómo se convierte PDF a imágenes?

    Selecciona “PDF → Imágenes”, añade uno o varios PDF y elige PNG o JPG. Se descargará una imagen por cada página del documento.
